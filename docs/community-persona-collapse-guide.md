# 给第一次整理人设的你：Persona Collapse 使用说明

> 适用于 SillyTavern Persona Collapse 3.2.7

如果你的人设列表已经变成了“同一个人几十套衣服、几十条时间线、几十个实验版本”，先别急着删卡，也不用重新命名所有文件。

Persona Collapse 的思路很简单：

> 把相关人设放进同一条分支，用一个入口代表它们；需要切换时，再从分支面板里选择。

它更像是给人设列表加了一层文件夹和目录，而不是改变你原本的人设内容。

---

## 一、先看懂它在做什么

假设你的列表原来是这样：

```text
Alice
Alice - 日常
Alice - 战斗服
Alice - 雨天
Alice - 长篇剧情
Bob
Bob - 学院线
```

整理后可以变成：

```text
Alice [4]
Bob [1]
```

点开 Alice 后，分支面板里会看到：

```text
Alice
日常
战斗服
雨天
长篇剧情
```

这里的 `Alice [4]` 是入口，下面的四个人设是分支成员。它们仍然是四个独立人设，只是被收纳在一起了。

## 二、安装：只需要复制三个文件

从项目发行版中找到：

```text
manifest.json
style.css
dist/index.js
```

把它们复制到：

```text
SillyTavern/public/scripts/extensions/third-party/persona-collapse/
```

文件夹结构应当是：

```text
persona-collapse/
├─ manifest.json
├─ style.css
└─ dist/
   └─ index.js
```

复制后刷新 SillyTavern。进入扩展设置，看到“人设折叠”就说明安装成功。

本版本提供的是可直接复制的文件夹，不需要手动解压项目自制 ZIP。

## 三、第一次使用：从一条小分支开始

不要一上来整理全部人设。建议先拿同一角色的两三张卡试用。

### 第一步：选择入口

在左侧点选你最常用的人设，例如 `Alice`。它会成为这条分支的入口。

### 第二步：打开管理面板

在当前人设的详情区域找到：

```text
管理分支卡片
```

打开后，你会看到一个管理面板：

- 左侧是可以加入的人设。
- 右侧是当前分支中的人设。

先搜索 `Alice`，把 `Alice - 日常` 和 `Alice - 战斗服` 加入右侧。

### 第三步：检查分支面板

关闭管理面板或返回人设详情区域，你会看到分支面板。此时 Alice 是入口，另外两张卡已经被收纳进去。

## 四、给分支建立文件夹

当分支成员多起来，建议使用具名分组。

### 新建分组

在分支面板点击“新建分组”，输入一个你能一眼看懂的名称，例如：

- `日常`
- `战斗服`
- `校园线`
- `已完成`

### 把人设放进去

拖动时请抓住人设行左侧的拖拽手柄。移动到目标分组后，等一条插入基线出现，再松开。

当前版本的拖动体验有两个重要特点：

1. 其它人设不会跟着你的鼠标不断跳动。
2. 被拖走的人设原位置会保留空白，基线表示松手后的落点。

空分组也可以接收第一个人设。只要把人设拖到空分组的主体区域，等待接收提示后松开即可。

### 分组可以怎么调整？

- 点击箭头或标题：展开、折叠分组。
- 点击铅笔：重命名分组。
- 点击垃圾桶：删除分组，成员会回到顶层。
- 拖动分组手柄：调整分组在顶层的顺序。

## 五、入口到底是什么？

入口就是分支顶层的第一位人设。

例如：

```text
Alice       <- 当前入口
日常
战斗服
```

如果你把另一张人设移动到顶层第一位：

```text
Alice - 战斗服  <- 新入口
日常
Alice
```

左侧列表显示的入口就会随之改变。

这不会删除 Alice，也不会改变角色绑定、聊天记录或群组关系。它只改变“这条分支在左侧由谁代表”。

## 六、管理面板：适合大量整理

当你有几十张人设时，管理面板更适合批量整理。

### 左侧人设库

可以使用：

- 搜索框找人设。
- 同名筛选。
- 同绑定筛选。
- 加入当前分支。

### 右侧当前分支

可以使用：

- 上下移动。
- 移入指定分组。
- 移回顶层。
- 设置入口。
- 删除或解散分组。

一个实用流程是：先用筛选器批量加入，再用右侧列表调整顺序，最后用分组名称整理结构。

## 七、自动收纳：先自动，再手动

扩展设置中有两种自动收纳方式：

### 按名称或前缀

例如：

```text
Alice
Alice - 日常
Alice - 战斗服
```

它们可能会被识别为同一组。

### 按角色绑定

如果多张人设在 SillyTavern 中绑定了同一个角色，插件可以据此进行收纳。

自动收纳适合做第一轮整理，但它不是不可修改的最终结果。你可以关闭自动收纳，再使用管理面板手动调整。

## 八、最容易遇到的几个问题

### “我拖了，但没有移动”

请检查：

1. 是否抓住了左侧拖拽手柄。
2. 是否已经看到插入基线。
3. 是否拖到了目标分组主体，而不是分组按钮。
4. 扩展设置是否已启用。

### “我找不到分支面板”

先在左侧点击一个人设，再看人设详情区域。独立人设会显示“管理分支卡片”按钮；已经有分支的人设会显示分支成员和分组控制。

### “删除分组会不会删掉人设？”

不会。删除分组只会移除这个具名分组，里面的人设会回到当前分支的顶层。

### “解散分支会不会删卡？”

不会。解散分支只取消收纳关系，人设本身仍然保留。

### “更新后还是旧界面”

确认目标目录中有最新的：

```text
manifest.json
style.css
dist/index.js
```

然后刷新 SillyTavern。必要时执行浏览器强制刷新。

## 九、推荐的整理顺序

如果你准备整理很多人设，可以按这个顺序来：

1. 先备份 SillyTavern 设置。
2. 开启按名称或绑定关系自动收纳。
3. 检查自动生成的分支，不满意的部分手动调整。
4. 用管理面板批量加入遗漏的人设。
5. 创建少量清晰的具名分组。
6. 把最常用的人设放到顶层第一位作为入口。
7. 关闭不需要的自动收纳选项。

不要一开始建立几十个分组。分组名称越少、层级越浅，日常切换越顺手。

## 十、一句话总结

Persona Collapse 不会替你删除或改写人设，它只是把散落在列表里的卡片整理成更容易理解的目录：

> 左侧找入口，分支里找版本，分组里找场景。
