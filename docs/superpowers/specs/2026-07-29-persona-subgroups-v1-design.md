# 人设分支一级分组设计规格

## 目标

在现有“人设分支”面板内加入一级、可命名、可折叠的分组，帮助用户整理同一主设下数量较多的人设变体。第一阶段保持 SillyTavern 原生人设列表和现有分支关系不变，不实现全局侧栏替换或多级嵌套。

## 已确认的产品决策

- 外层面板标题固定为“人设分支 (数量)”，取消标题编辑入口。
- 只允许一层分组，不允许组内再建组。
- 主设行始终固定显示在分组列表上方，不加入子组，也不会被折叠隐藏。
- 分支成员可以放入一个命名组；没有归属的成员显示在“未分组”区域。
- 命名组和“未分组”都可独立折叠，折叠状态跨刷新保存。
- 删除命名组只把其中成员移回“未分组”，不删除人设、不解除分支关系、不改变角色绑定。
- 复制人设仍执行完整复制且不复制绑定关系。若源人设位于命名组，副本进入同一组并紧跟源人设；否则副本进入“未分组”并紧跟源人设。

## 界面与交互

面板结构固定为：

1. “人设分支 (数量)”标题与现有管理按钮。
2. 主设行。
3. 零个或多个命名组。
4. “未分组”区域。

标题区增加“新建分组”图标按钮。新建后生成默认名称“新分组”，立即进入内联重命名状态；名称去除首尾空白，空值恢复为“新分组”。允许重名，因为分组由稳定 ID 标识。

命名组标题行显示折叠箭头、组名、成员数量、铅笔按钮和删除按钮。删除前使用现有 Popup 风格确认。成员行增加一个轻量的“移动到分组”操作，菜单包含全部命名组和“未分组”；移动后保留该成员在分支中的相对顺序。

“未分组”在有成员时显示；没有成员时仅在存在命名组时显示空状态，以提供明确的移出目标。所有按钮使用 Font Awesome 现有图标、`title` 提示和键盘可操作的 `button` 元素。

## 数据模型

在 `GroupSettings` 增加：

```ts
interface PersonaSubgroup {
  id: string;
  name: string;
  personaIds: string[];
  collapsed: boolean;
}

subgroups: Record<string, PersonaSubgroup[]>;
ungroupedCollapsed: string[];
```

`subgroups` 的键是主设 `parentId`。数组顺序决定命名组显示顺序，`personaIds` 顺序决定组内显示顺序。“未分组”不重复存储成员，而是从有效分支成员减去所有有效 `personaIds` 后派生，避免自动分组变化造成双重状态。

读取旧设置时缺失字段自动补默认值，不写破坏性迁移。原有 `groupNames` 数据保留但不再用于面板标题，以便降级到旧版本时仍可恢复；本阶段不删除它。

## 状态规则

- 同一 `parentId` 下，一个人设最多属于一个命名组。移动操作先从其他组移除，再插入目标组。
- 自动或手动分支新增成员默认进入“未分组”。
- 分支成员被移除或人设被删除时，从所有 `personaIds` 清理其 ID；空的命名组保留，直到用户主动删除。
- 主设被删除或分支被解散时，删除对应的 `subgroups[parentId]` 和未分组折叠状态。
- “提升为主设”时，将原主设对应的子组数据迁移到新主设 ID；旧主设作为普通成员后进入“未分组”。
- 当前选中人设位于折叠组内时，组保持用户设定的折叠状态，不自动展开；主设行和组标题仍提供上下文。

## 代码边界

- `src/manager.ts` 负责数据默认值、创建/重命名/删除/折叠/移动/清理/主设迁移等纯状态行为。
- `src/index.ts` 负责渲染组结构、绑定按钮事件，并在复制完成后调用 manager 将副本放到正确位置。
- `style.css` 只增加组标题、缩进、空状态和移动菜单所需样式，保持当前紧凑面板视觉。
- 新增 `tests/manager.subgroups.test.ts`，直接测试状态模型，不依赖 SillyTavern DOM。

## 安全与兼容

组名通过文本节点或现有 `escapeHtml` 输出，禁止直接插入未转义 HTML。设置读取必须容忍旧版、缺字段和残留无效 ID。新增 UI 文本通过一个局部翻译辅助函数调用 SillyTavern 的 `i18next.t` 并提供中文默认值；若运行环境没有翻译实例，退回中文，不影响加载。

参考脚本 `酒馆助手脚本-人设角色适配器_v1.29_修订2_切换刷新轻量化版.json` 仅用于借鉴稳定 ID、文件夹独立折叠和派生未分组的思路，不复制其全局原生列表覆盖、深层管理树或大规模状态模型。

## 测试与验收

自动测试覆盖：

- 旧设置加载时补齐新字段且保留 `groupNames`。
- 新建、重命名、折叠和删除组。
- 人设只能属于一个组，移动和组内顺序正确。
- 删除组后成员派生为未分组，绑定和分支数据不变。
- 复制后的目标位置解析：继承源组或进入未分组。
- 清理已删除人设、解散分支和提升主设时的数据迁移。

验收还包括生产构建成功、压缩包仅包含运行所需文件，并手动检查桌面与窄屏下标题、组名、按钮不重叠。发布时先在功能分支形成可回退提交；验证通过后合入 `source`，再单独生成纯运行文件更新 `main`，两条分支各自保留独立发布提交。

## 明确不在第一阶段实现

- 覆盖或替换 SillyTavern 原生左侧人设列表。
- 按绑定角色筛选、全局搜索、批量移动。
- 多级文件夹、拖拽排序、跨主设移动。
- 删除组时删除人设或修改任何角色绑定。

这些能力后续分别进入“筛选管理”和“可选全局管理面板”阶段，避免本次改动扩大 DOM 兼容风险。
