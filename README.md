# SillyTavern Persona Collapse

> 把一长串人设卡，整理成清楚、好找、随时能切换的分支树。

Persona Collapse（人设折叠）是一款 SillyTavern 前端扩展，适合拥有多套马甲、不同设定、不同注入配置的人设用户。它把相关人设收进同一条分支，并提供折叠、分组、排序、批量管理和自动收纳功能。

当前版本：**3.2.7**

## 它解决什么问题？

如果你的左侧人设列表像这样：

```text
Alice
Alice - 日常
Alice - 战斗
Alice - 节日
Alice - 长篇设定
Alice - 实验版
```

你可以把它整理成：

```text
Alice  [5]
├─ 日常
├─ 战斗
├─ 节日
├─ 长篇设定
└─ 实验版
```

左侧只保留一个入口，进入后再从分支面板切换具体人设。

## 主要功能

### 分支折叠

- 将多个相关人设收进同一条分支。
- 左侧入口卡显示分支数量。
- 点击入口后，在人设管理区域查看分支成员。
- 分支成员不会重复占满左侧列表。

### 自定义分组

- 在分支面板中新建具名分组，例如“日常”“战斗服”“剧情线”。
- 人设可以在顶层和分组之间移动。
- 分组可以折叠、展开、重命名、删除和调整顺序。
- 同一分支可以同时存在未分组人设和多个具名分组。

### 稳定拖拽

- 拖动时其它人设保持原有布局。
- 被拖人设原位置保留空白，不新增可见占位卡。
- 插入基线显示最终落点。
- 跨分组拖动时可以直接进入目标分组。
- 取消拖动或触屏中断时会自动清理拖动态。

### 批量管理

管理面板提供：

- 人设搜索。
- 按同名或绑定关系筛选。
- 将人设加入当前分支。
- 将人设移动到顶层或其它分组。
- 上下移动人设。
- 删除分组或解散整条分支。

### 自动收纳

在扩展设置中可以分别开启：

- 按名称或名称前缀自动收纳。
- 按绑定到同一角色自动收纳。

自动收纳适合先整理大量人设，再用手动分组微调。重要的人设建议整理后检查一次入口和分组位置。

### 复制人设

分支面板中的复制按钮可以复制人设名称、描述、注入设置、世界书和头像，并自动加入当前分支。

复制不会复制角色、聊天或群组绑定关系。

## 新手快速开始

### 1. 安装扩展

将仓库中的以下文件复制到 SillyTavern 的第三方扩展目录：

```text
manifest.json
style.css
dist/index.js
```

目标目录：

```text
SillyTavern/public/scripts/extensions/third-party/persona-collapse/
```

最终结构应类似：

```text
persona-collapse/
├─ manifest.json
├─ style.css
└─ dist/
   └─ index.js
```

本项目发行时使用可直接复制的文件夹，不要求使用自制 ZIP。复制完成后刷新或重启 SillyTavern。

### 2. 打开扩展

在 SillyTavern 的扩展设置中找到“人设折叠”，确认启用。

### 3. 组建第一条分支

1. 在左侧选择一个准备作为入口的人设。
2. 在人设详情区域点击“管理分支卡片”。
3. 在管理面板左侧找到要加入的其它人设。
4. 点击加入按钮，将它们放入当前分支。
5. 回到分支面板，确认成员顺序。

### 4. 新建具名分组

1. 打开分支面板。
2. 点击“新建分组”。
3. 输入名称，例如“日常线”。
4. 将人设拖到分组的插入基线位置。

空分组也可以接收第一个人设。拖动时请抓住人设行左侧的拖拽手柄，看到基线后再松开。

### 5. 更换入口

分支顶层的第一位人设就是左侧列表中的入口。将另一位人设移动到顶层第一位，即可更换入口。

入口只是显示入口，不会改变角色、聊天或群组绑定关系。

## 你需要记住的三个概念

| 概念 | 含义 |
| --- | --- |
| 分支 | 一组相关人设的集合，左侧用一个入口表示 |
| 顶层 | 分支内没有放进具名分组的人设区域 |
| 入口 | 顶层第一位人设，代表这条分支出现在左侧列表中的卡片 |

## 常见操作

### 把人设移入分组

抓住人设行左侧的拖拽手柄，移动到目标分组内。看到插入基线后松开。

### 把人设移回顶层

将人设拖到分组外的顶层区域，或在管理面板中选择“移动到顶层”。

### 调整顺序

在同一层级内拖动人设或分组。拖动过程中以基线为准，不要根据卡片是否提前移动来判断位置。

### 删除分组

删除分组不会删除其中的人设，人设会回到当前分支的顶层未分组区域。

### 解散分支

解散分支会取消这一组人设的分支关系。它不会删除人设文件。

## 常见问题

### 安装后看不到更新

确认目录中至少有：

```text
manifest.json
style.css
dist/index.js
```

然后刷新 SillyTavern 页面。若浏览器仍使用旧缓存，可以执行一次强制刷新。

### 拖动没有反应

- 确认扩展已启用。
- 从左侧拖拽手柄开始拖动，不要抓住按钮或头像操作区。
- 移动到目标位置后等待插入基线出现。
- 不要在拖动过程中频繁点击其它按钮。

### 第一个人设放不进空分组

请将人设拖到空分组的主体区域，等待出现“拖入人设”的接收提示，再松开。当前版本支持空分组接收第一个成员。

### 自动分组和手动分组冲突

自动收纳适合做初步整理。需要固定结构时，可以关闭对应的自动收纳选项，再用管理面板手动调整。

## 安全说明

- 分组操作只修改 SillyTavern 的扩展设置，不删除人设文件。
- 复制人设会创建新的头像和人设记录，请在确认名称后使用。
- 更新扩展前建议备份 SillyTavern 的扩展设置。
