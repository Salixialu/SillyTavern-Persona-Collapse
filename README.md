# 🎉 SillyTavern Persona Collapse (人设折叠)

还在为 SillyTavern 左侧列表里长长的一长串“同一角色的不同换装/不同设定卡”感到头疼吗？找一张特定的卡要向下划半天？
隆重向大家介绍这把左侧栏的“收纳神器”—— **Persona Collapse (人设折叠)**！

这是专为**多马甲/多设定党**量身定制的拓展插件。它能将同一角色的各种变体卡片折叠成“主副卡分支”的树状结构，让你的界面瞬间清爽干净！

---

## ✨ 核心亮点功能

### 🗂️ 1. 丝滑的分支折叠体验
你可以将同一角色的换装卡、差分卡收纳成一条人设分支，并随时调整左侧列表入口。
在左侧栏，入口卡右上角会显示一个**精致低调的半透明毛玻璃角标**（提示里面收纳了几张卡）。点击入口卡后，专属的“人设分支”面板会自动在下方展开，随时随地快速切换！

### 📁 2. 分支内自由分组与排序
人设与具名折叠组可以自由混合排序；拖入分组即可收纳，拖回顶层即可移出。分组本身也能调整位置，点击整条标题或箭头可展开和收纳。

顶层第一位人设是该分支在左侧列表中的动态入口。将其他人设拖到第一位即可更换入口，不会修改角色、聊天或群组绑定关系。

每个人设同行提供快速复制按钮：复制名称、描述、注入设置、世界书和头像等完整人设内容，但**不会复制角色、聊天或群组绑定关系**。副本会紧跟源人设，并自动进入源人设所在的命名组。

### 🤖 3. 懒人福音：双轨全自动收纳
不想手动一张张整理？插件支持全自动归类（可在顶部拓展设置面板开启）：
- **按同名前缀收纳**：自动将名字前缀相同的人设归入一组（如 \Alice_战斗服\ 会自动归入 \Alice\ 之下）。
- **按角色绑定收纳**：如果你在原版酒馆里为卡片绑定了特定角色，插件会自动读取绑定关系，把它们智能打包在一起！

### 🛠️ 4. 极速“批量管理”控制台
点击独立角色卡下方的 \[🛠️ 管理分支卡片]\ 按钮，即可呼出强大的双栏管理面板！
左侧是角色库，右侧是当前分支。你可以使用自带的**搜索框**和**快捷筛选器（同名/同绑定）**，一键选中多张卡片，瞬间完成海量分支的组建与拆解。

### 🌍 5. 无缝原生融合
无论是全局的角色选择弹窗，还是右键菜单，插件都做了深度原生适配。
弹窗里只显示主卡，绝不让分支卡出来占位置；支持顺滑的拖拽排序与放入，拥有近乎原生自带功能般的完美体验！

## 🚀 安装与使用指引

📦 **如何安装**：

1. 推荐在 SillyTavern 的“安装扩展”中填写：`https://github.com/Salixialu/SillyTavern-Persona-Collapse`。
2. 也可以导入 `persona-collapse.zip`，或将其解压到 `SillyTavern/public/scripts/extensions/third-party/`。
3. 确认最终路径为 `third-party/persona-collapse/manifest.json`，然后重启酒馆。

---

💡 **小贴士**：
如果你是第一次使用，建议先在左侧点选人设，然后点击下方的 \[🛠️ 管理分支卡片]\ 按钮，试试全新的搜索归纳功能，几秒钟就能把几十张卡整理得服服帖帖！
